# Zarobek: fabryka mikrotooli
KIEDY: wlasciciel chce pasywny dochód - male narzedzia na sprzedaz.

ZASADY: produkt wlasny (bez kopiowania cudzych licencji); wystawia WLASCICIEL (konto/platnosc). Bez obietnic sprzedazy.

KROKI:
1. Wybierz nisze: skrypt/konwerter/kalkulator/szablon arkusza/pakiet promptów.
2. Zrob dzialajacy produkt: kod + README (co robi, jak uruchomic, przyklad) + LICENSE (MIT).
3. PRZETESTUJ (uruchom, pokaz wynik = dowod).
4. Zapakuj: folder + ZIP; dodaj krotki opis sprzedazowy (1 akapit) i 3 pomysly na tytul.
5. RAPORT: co gotowe, gdzie wystawic (Gumroad/Etsy), sugerowana cena (bez gwarancji).
