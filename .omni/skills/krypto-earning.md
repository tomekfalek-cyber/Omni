# Zarabianie kryptowalut (legalne okazje)
KIEDY: uzytkownik pyta jak zarobic krypto, szuka airdropow, bounty, stakingu, learn-to-earn.

TWARDE ZASADY:
- Pomagam ZNALESC i ZROZUMIEC legalne okazje. NIE obiecuje zysku ani nie gwarantuje zarobku.
- NIE tworze automatow do masowego zakladania kont ani farmienia airdropow (sybil) - to lamie ToS i jest oszustwem.
- NIGDY nie prosze o seed/klucz prywatny i ich nie przechowuje - portfel zostaje u uzytkownika.
- Sprawdzam regulamin (ToS) platformy, zanim cokolwiek zasugeruje.
- Ostrzegam o scamach: darmowe 'podwojenie', prosba o klucz/seed, presja czasu, nieznane linki.

KROKI (research):
1. Ustal typ okazji: airdrop, bug bounty, learn-to-earn, staking/yield, freelancing/Dao.
2. Zbierz kandydatow: news, web_search, fora, OFICJALNE strony projektu.
3. Weryfikuj legalnosc: oficjalne kanaly, zespol, audyty, historia; unikaj 'za darmo'.
4. Red flags: prosba o seed/fundusze, 'gwarantowany zysk', link skracany, brak zespolu.
5. Opisz udzial krok po kroku (bez automatow, bez wielu kont).
6. Ryzyka: podatki, zmiennosc kursu, ToS, oszustwa; nagrode wycen narzedziem crypto_price.

ZRODLA: news, web_search, web_fetch (oficjalne strony), crypto_price (wycena nagrod).
